# Agent Development Guidelines Template

Guidelines for AI agents and human contributors working on this repository.

## 1. Quick Architecture Map

| Layer               | Path                     | Responsibility                              |
| :------------------ | :----------------------- | :------------------------------------------ |
| **Frontend UI**     | `src/client/components/` | Reusable React UI components                |
| **Frontend Routes** | `src/client/routes/`     | File-based client routing                   |
| **API Endpoints**   | `src/server/routes/`     | OpenAPI / RPC router and request handlers   |
| **Database**        | `src/server/database/`   | Drizzle / Prisma / SQLite schemas and seeds |
| **Shared Types**    | `src/shared/types/`      | Cross-boundary DTOs and contracts           |
| **CI & Tooling**    | `scripts/`, `.github/`   | Verification tasks and automated workflows  |

---

## 2. Core SSOT & Architectural Invariants

- **Single Source of Truth (SSOT)**: Domain contracts are defined once in `src/shared/` and inferred downstream.
- **Unidirectional Data Flow**: State mutations occur via server actions or verified mutations; components reflect derived state.
- **Domain Rules Location**: Path-specific rules are modularized under `.agents/rules/` (`api-routes.md`, `ui-components.md`, `database.md`) and automatically activate via file globbing.

---

## 3. Frictionless Agent Execution (Whitelist-First)

In this project, always prioritize `vp run agent:*` or `vpr agent:*` commands to bypass execution prompts:

- **Verification Gate**: `vpr agent:verify:gate`
- **Lint & Fix**: `vpr agent:lint:fix`
- **Type Checking**: `vpr agent:typecheck`
- **Unit Testing**: `vpr agent:test:unit`

---

## 4. Language & Planning Standards

- **Traditional Chinese for Plans and Responses**: All implementation plans (`/plan`), walkthrough artifacts, design documents, and conversational responses generated by AI agents must strictly be written in **Traditional Chinese (繁體中文)**.
- **Code Artifacts**: Source code, inline comments, commit messages, and automated tests must use concise English.
